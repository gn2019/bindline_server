Introduction

BindLine is a tool for exploring protein–DNA interactions based on Protein Binding Microarrays (PBM) results. PBM experiments provide quantitative binding scores for all possible DNA k-mers (sequences in lengths "k"), allowing visualization of binding strength along full DNA sequences rather than relying only on motifs. BindLine helps identify binding sites directly from the data, even when no single consensus motif exists. TODO TODO TODO Something about interactivity TODO TODO TODO

Scoring

Load Sample

BindLine works with three PBM score types:

  • I-Score – median intensity of the k-mer in the univeral microarray - the "raw" measurement
  • Z-Score – statistical significance of binding, in which 0 is the median intensity across k-mers
  • E-Score – normalized enrichment of each k-mer, in the range -0.5 to 0.5. This measurement relies on ranking of the k-mer scores, and is more robust
Some of the public results, and possibly yours, has only part of the score types. Types that are excluded from the uploaded results are unsupported. You can choose the desired type before analysis. You may use existing public results or use your own. As a logged-on user you may upload files for a continuous use.
You may explore the binding across one or more sequences. You may use public fasta files, containing known promoters and enhancers, or upload your own. The “Load Sequences” button allows reviewing or preparing sequences before plotting. You may avoid using files and use the sequences table directly. All sequences in a single analysis file should align. One of them (the first by default) is considered as reference ("ref") and the others are considered as its mutations. This way, you can view the effect of insertions, deletions and base substitutions.
The "BindLine" plot shows the chosen scores across the aligned sequences. The "ref" sequence is the one shown in the x-axis, and the others are aligned to it. Each point in the "BindLine" plot represents the score for the k-mer starting in this nucleotide.
Stacked and Tabbed visualization modes are options for presentations of the plots.

Threshold Settings

Load Sample

BindLine offers optional thresholds for each score type. You may enable and adjust them with sliders or numeric input fields. Ranks thresholds, which highlight only the top-scoring k-mers, are also available. When using a threshold, the "Binding Sites" plot appears. Each sequence that is above the threshold is called here a binding site. The "Binding Sites" plot shows which proteins compete on the same binding sites and which may interact as their binding sites are nearby. Deletions are shown in this plot as black rectangles, and insertions as black triangles.

Search for binding sites across all proteins

Load Sample

BindLine allows searching for binding sites across all the results - public and yours - instead of using certain results. For this, you must choose a threshold to view only proteins that their score overcomes it for at least one k-mer in the sequences. We recommend not to use a low threshold, as the results will be noisy.

Search for significant point mutations

Load Sample

BindLine allows searching for binding sites across all sequences derived from one sequence by single point mutations - 1-base substitutions, insertions and deletions. For this, you must choose a threshold to view only sequences that their score overcomes it for at least one k-mer in the sequences. Mutations which cause the same behavior are shown only once (for example: if AAAA is a binding site and the uploaded sequence is AAAC, substitution C->A and insertion of A before the C are considered the same and only one of them is shown). When using this option, the "All Mutants" plot appears. "All Mutants" plot shows the effect of each substitution on the score, both positively and negatively. This type of plot is ussually used to show Massively Parallel Reporter Assay (MPRA) reaults, and can be compared to them to find the transcription factor causing the differences in gene expression.

Show diff from reference sequence only

Load Sample

BindLine allows searching only the major differences between sequences - only the ones which create or destroy a binding site, as defined by the threshold selected. When using this option, only sequences that are different from the "ref" sequences are shown, as well as the "ref" sequence itself. De-Novo binding sites are shown in color, and destroyed binding sites are shown in gray.
